---
name: Guidance trust model
description: Durable rules for presenting maintained immigration guidance and policy updates.
---

Official and community guidance must never be presented as equivalent. Each visa or policy claim needs an authority label, a direct source URL, and a reviewed-on date; uncertain figures should point users back to the official source before action.

**Why:** Immigration fees, eligibility rules, occupation lists, and processing expectations can change and stale advice can cause real harm.

**How to apply:** Keep runtime guidance records in the maintained data store, expose source metadata through the API, and render an explicit reviewed/source trail wherever a user sees a material claim.
